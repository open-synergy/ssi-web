=======================
Web Permanent Menu Icon
=======================

Lets a menu icon that was customized through the *Menu Items* form
(``Settings > Technical > User Interface > Menu Items``, developer mode)
survive later module updates. Without this module, updating the module
that owns the menu (``odoo -u <module>``) always rewrites the icon back
to its XML definition, discarding any manual change.


Installation
============

To install this module, you need to:

1.  Clone the branch 14.0 of the repository https://github.com/open-synergy/ssi-web
2.  Add the path to this repository in your configuration (addons-path)
3.  Update the module list (Must be on developer mode)
4.  Go to menu *Apps -> Apps -> Main Apps*
5.  Search For *Web Permanent Menu Icon*
6.  Install the module
