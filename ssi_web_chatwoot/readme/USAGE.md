1. Go to *Settings ▸ Technical ▸ Chatwoot Configuration*.
2. Create a configuration with the Chatwoot **Base URL** and **Website
   Token** of the inbox to connect to, then activate it.
3. Optionally restrict visibility to specific groups in the **Visibility**
   tab, or enable **Identity Validation** with the inbox's HMAC token so
   contacts are recognized as authenticated Odoo users.
4. Reload the backend. A headphone icon appears in the systray, next to
   the internal chat icon, for every user allowed to see it.
5. Click the icon to open the Chatwoot support widget panel.
