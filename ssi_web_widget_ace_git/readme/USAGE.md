1. Open any form with an Ace/Code editor widget, for example a Server Action
   or an Automated Action:

   ```xml
   <field name="code" widget="code"/>
   ```

2. Enter edit mode.
3. Click **"Fetch from GitHub"** below the editor.
4. Enter the GitHub file URL and, for private repositories, a Personal
   Access Token.
5. Click **"Fetch & Apply"**.
