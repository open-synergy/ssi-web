Open any list, kanban or other view that has a search bar. Apply one or more
filters and/or a group by so at least one facet appears next to the search
input.

A small "x" ("Clear All Filter") button appears at the far right of the
search bar. Click it to remove every active facet — including group by — in
a single click; the view goes back to showing all records matching the
action's domain.

Without any active facet, the button does not show and the search bar looks
exactly like standard Odoo.
